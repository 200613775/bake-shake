BAKE & SHAKE WEBSITE - HOW TO UPDATE

1. Open content.js in Notepad (or VS Code).
2. Change only the text between the quotes. Keep commas, [ ], { } as they are.
3. Menu: each category has a list of items. Copy one { name: ... }, line to add an item.
4. Opening hours: use 24-hour time like "12:00-20:00", or "closed".
5. Photos: save them in the images folder, then use them in photos: [ ], stories, or heroImage.
6. Email sign-up: works when the site is hosted on Netlify. Sign-ups appear in the Netlify dashboard under Forms.
7. Save, then upload the whole folder to Netlify again (drag and drop).
8. Keep a backup copy of content.js before you edit.
